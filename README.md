# 站牌工坊 · 福州公交站牌生成器

一个纯前端的福州公交站牌生成器：改线路号、选公司、载入高德线路，实时生成 1280×318 的公交站牌，并支持 PNG 导出和车站线路长图。

![K6 常规站牌](samples/K6-常规.png)

## 功能

- **站牌实时预览 / 导出**：1×、2×、3× PNG，默认 2×。
- **公司自动识别**：按线路号自动切换福州公交集团、康驰、闽运；底色、Logo 同步。
- **高德线路**：按线路号查线，载入真实路径、全部途经站、首末班时间和票价。
- **换向**：自动线路读取高德对向线路；普通线路退化为反转站点顺序。
- **手动加站连线**：自动线路上手动加入的站点如果不在高德真实路径上，会从相邻站点（例如 31 站到 32 站）调用高德「驾车路径规划」沿道路连接，线宽和颜色与主线路一致；结果缓存 30 天，失败时退回直线。
- **站点管理**：改名、拖动/箭头排序、设为当前站、双击查看车站详情。
- **设施标记**：200m 内最近的地铁站/医院自动点亮；2 QPS 限速 + 本地缓存；「启用标记」默认关闭，开启后可选「仅显示缓存」或「启动更新」（缓存优先：先用缓存、缺的再查高德）。
- **车站详情长图**：按公交站两侧分别生成长图，一条线路一张完整站牌，K 线在前、数字线从小到大、特殊线在后，可下载 PNG。
- **站名排版**：所有单字横向宽度统一，字高按字数纵向压缩（5 字内 100%、6 字 85%、7 字 73%、8 字 63%…）；站间距自动分配，优先保证单字宽度；首字贴顶、末字贴底，底边全部对齐；末尾括号单独成列。

## 技术

- 原生 HTML / CSS / JavaScript，无框架、无构建步骤。
- Canvas 2D 同时用于预览和 PNG 导出。
- 高德地图 JS API 2.0：`PlaceSearch`、`LineSearch`、`StationSearch`。

## 本地运行

不能直接双击 `index.html`（浏览器会限制部分本地资源），请用任意静态服务器：

```bash
python -m http.server 4173 --bind 127.0.0.1
```

然后打开 <http://127.0.0.1:4173/>。

## 配置高德 Key

本仓库**不包含任何 Key**。首次打开时地图是空的：

1. 在高德开放平台创建「Web端（JS API）」Key 和 securityJsCode；
2. 在站牌页面打开「地图设置」，填入 Key、securityJsCode 和城市；
3. 保存后连接地图。

Key 存放在浏览器 localStorage，不会上传到仓库。若部署到 GitHub Pages，需要把 `https://<你的用户名>.github.io` 加入高德 Key 的域名白名单。

## 部署到 GitHub Pages

1. 新建一个 **Public** 仓库，例如 `fuzhou-bus-sign`，不要勾选自动创建 README。
2. 打开仓库的 **Add file → Upload files**，把本文件夹里的内容拖进去（`index.html`、`app.js`、`style.css`、`config.js`、`assets/`、`samples/`、`README.md`、`LICENSE`）。提交。
3. 仓库 **Settings → Pages**：
   - Source 选 **Deploy from a branch**
   - Branch 选 **main**，目录选 **/(root)**
   - 保存。
4. 等 1–2 分钟，访问 `https://<你的用户名>.github.io/fuzhou-bus-sign/`。

> 建议不要把自己的 Key 写进 `config.js` 再提交。让每位使用者填自己的 Key，或只给自己的域名加白名单。

## 已知限制

- 高德接口有 QPS 和每日额度限制；项目已做 2 QPS 排队、缓存和单次查询上限。
- 车站详情线路很多时需要等待一段时间，弹窗里会显示预计剩余时间。
- 高德部分线路不返回票价（`basic_price/total_price = 0`），此时保留手动票制。
- 不同城市的公交数据完整度不同，默认城市是福州。
